# Project Description

Tool Hazard is a modern, all-in-one modding and research utility written in C# (.NET 8, WinForms), designed for classic survival horror titles such as Biohazard / Resident Evil 1–3, White Day (2001), and selected legacy console formats.

Originally started as White Day Mod Tool, it evolved into a full-featured toolkit inspired by [Biofat](https://www.romhacking.net/utilities/1019/), focused on reverse-engineering, modding, file editing, and preservation of classic game assets.

Tool Hazardは、C#（.NET 8、WinForms）で書かれた、最新のオールインワン型モッディング＆リサーチユーティリティです。バイオハザード/バイオハザード1～3、ホワイトデイ（2001年）、そして一部の旧型コンソール向けに設計されています。

当初はホワイトデイ・モッディングツールとして開発が始まりました。その後、Biofatに着想を得て、リバースエンジニアリング、モッディング、ファイル編集、そしてクラシックゲームアセットの保存に特化したフル機能のツールキットへと進化しました。

# Features

* Biohazard/Resident Evil 1-2-3:
  * Unpack/Repack RDT files (BIO1 not tested).
  * Support for EMD/PLD viewing & editing for RE1,2,3
  * Support for Message (.MSG) file editing for RE1,2,3
  * Support for viewing PIX files and converting them to PNG and BMP and vice versa; supports both singular pix (like TITLE.PIX) and small icons pix sheets (like ITEM_ALL.PIX)
  * SCD OpCode Editor (Only Biohazard 3 tested); with drag-drop updatable opcode database in the form of .json files based on [CRE-SCD-BHS Biohazard SCD Editor](https://github.com/3lric/CRE-SCD-BHS/)
  * Support for RE2 (1998) PC Sound Files, complete with playaback, export, repack, with OGG (Classic Rebirth) support as well.
  * Classic Rebirth
    * Ability to Install [Gemini-Loboto3](https://github.com/Gemini-Loboto3)'s [Classic Rebirth](https://classicrebirth.com/) patch from the tool's interface.
    * File Editor
    * BGM XML Editor
* White Day (2001):
  * NOP file extraction (the repack functionality is a work in progress).
  * Supports extraction of files with Korean character file names without the need of Locale Emulator.
  * Font Editor: this is a part of Gemini's File Editor in C Sharp/C#.
* Nintendo DS
  * Content Scanner + Lz77Wii Decompressor
* Sony PS1
  * TIM Viewer complete with multipack and multiclut support.
  * TIM to PNG/BMP/PIX (BIO) and vice versa.
* Resident Evil 4 (RE4 / BIO4) — Model Viewer (JADERLINK_MODEL_VIEWER port)
  * Unified Model Viewer now opens RE4 `.BIN` meshes: UHD (PC), X360/PS3 (BE), PS4/Switch (wide), GC/Wii, and PS2 VIF (read-only).
  * BIO4 `.TPL` reference tables link BIN materials to `.PACK` textures (PackID/TextureID) across all four families; GC/Wii embedded TPL headers are parsed as well.
  * `.PACK` textures decoded natively (DDS uncompressed + DXT1/3/5 subset, TGA uncompressed/RLE truecolor/colormapped); GNF entries pass through raw (Scarlet decode not vendored).
  * 2007 `.PMD` meshes and binary scenario `.SMD` containers (embedded BIN/TPL extraction + placed OBJ export), text `.SMD`, generic `.OBJ`, and `.SMX` metadata inspection.
  * Mesh export to OBJ (+MTL)/SMD; OBJ/SMD import patches UHD BINs in place when vertex/triangle counts match, otherwise opens as a generic view.
  * Texture export to PNG/BMP and PNG/BMP replacement re-encoded to DDS (A8R8G8B8) or TGA in place; BIN/TPL saved as patched clones (all untouched sections byte-preserved), PACKs rebuilt with fresh offsets.
* PC Game Boost (Windows 11 speed + gaming optimizer)
  * `Extras > Game Boost > Open Game Boost Panel`: live checklist (Power plan, Game Mode, HAGS, Game DVR capture, Visual FX, transparency, mouse accel, background apps, throttling, temp, startup) with one-click Apply/Revert.
  * User-level (no admin): Game Mode ON + Game DVR background capture OFF, Visual Effects -> Best performance, transparency/animations OFF, mouse raw input (1:1), Taskbar bloat OFF, background apps OFF, power throttling OFF, `%TEMP%` cleanup.
  * Elevated (admin, via PowerShell scripts in `pc-hardening/`): Hardware GPU Scheduling (HAGS) ON, Ultimate Performance power plan + PCIe ASPM OFF, CPU foreground scheduler boost (`Win32PrioritySeparation=38`), SysMain/WSearch/DiagTrack -> Manual, telemetry + Delivery Optimization policies.
  * Launch games with Boost: pick any `.exe`, sets High-performance GPU preference, lowers Edge/Discord-class background apps to BelowNormal and launches the game at High priority; Restore Priorities button undoes it.
  * Exportable PowerShell equivalents (`pc-hardening/Apply-GameBoost.ps1`, `Apply-GameBoost-Elevated.ps1`, `Revert-GameBoost-Elevated.ps1`) so tweaks can be applied without the app.
